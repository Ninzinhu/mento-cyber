# Plano de baixo custo — comunidade MentoCyber

## Objetivo

Criar uma comunidade de prática sustentável sem antecipar infraestrutura cara nem cobrar
pelo conhecimento básico. A prioridade é publicar boas missões, facilitar encontros e
manter uma moderação saudável.

## Ferramentas iniciais

| Necessidade | Opção inicial | Custo esperado |
| --- | --- | --- |
| Site e documentação | Next.js em Vercel ou Cloudflare Pages | faixa gratuita |
| Conversa entre pares | Discord ou Matrix | faixa gratuita |
| Agenda de encontros | Cal.com ou Google Calendar | faixa gratuita |
| E-mail | Resend | faixa gratuita inicial |
| Formulários de interesse | Tally ou formulário próprio | faixa gratuita |
| Arquivos públicos | Cloudflare R2 ou GitHub | custo baixo por uso |
| Dados quando necessários | Supabase ou Neon | faixa gratuita inicial |

## O que evitar no começo

- Plataforma LMS, certificados e painel de “progresso de aluno”.
- Paywall para checklists, referências ou primeiras missões.
- Labs persistentes e caros antes de haver prática recorrente.
- Automação de moderação sem pessoas responsáveis pelas decisões.

## Sustentação possível

1. Apoio recorrente voluntário com transparência sobre o destino dos recursos.
2. Patrocínio ético de organizações alinhadas à defesa digital responsável.
3. Oficinas ou encontros para organizações, sem transformar a comunidade em funil de curso.
4. Doações pontuais para bancar moderação, domínio, encontros e infraestrutura.

## Sinais para investir mais

- Pessoas retornam às missões e revisam contribuições de outras pessoas.
- Os encontros possuem pauta, registro e continuidade.
- A moderação começa a demandar ferramentas próprias.
- Há demanda real por ambientes isolados para práticas específicas.

## Próximo ciclo

Publicar uma missão aberta, organizar uma roda de revisão e registrar o que a comunidade
mudou de ideia. Só depois disso escolher autenticação, banco de dados ou recursos pagos.
